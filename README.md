### ⚡ Key Modules

### ⌨️ Relax Engine
Advanced key input automation with customizable humanization and stamina emulation.
* **Smart Key Bindings:** Fully rebindable primary and secondary key triggers.
* **Precision Timing Control:** Adjustable hit window, offset drift, UR (Unstable Rate) target, and randomness values.
* **Hold Duration Adjustment:** Independent circle/slider hold durations with micro-error offsets for realistic replay data.
* **Alternation Mechanics:** Single-tap stream toggles, alternate-key logic, and dynamic stream detection thresholds.
* **Humanized Stamina System:** Dynamic drain rates, BPM weight adjustments, and recovery rate emulation to simulate real physical fatigue.

### 🎯 Aim Correction & Assist
Discreet cursor tracking helper with real-time target detection.
* **FOV & Activation Range:** Custom activation radius (px) and field-of-view limits.
* **Dynamic Pull Strength:** Smooth cursor pull adjustments without snapping.
* **Auto-Calibration:** One-click automated position offset correction (X/Y).
* **Aim Ahead & Slider Follow:** Predictive cursor positioning with look-ahead latency and automatic slider path tracking.

### 🧩 Additional Modules
* **Playbot:** Fully automated map replay execution mode.
* **Enlighten:** Visual map enhancement and object visibility utility.
* **Tap Assist:** Micro-timing assistance for mixed singletap/stream patterns.
